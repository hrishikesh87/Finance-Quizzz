# 💰 Finance MCQ Bank

A professional, interactive finance quiz app with **200 MCQs** across 10 core finance topics.

## Topics Covered
- Time Value of Money
- Capital Budgeting
- WACC & Cost of Capital
- Equity Valuation
- Financial Statement Analysis
- Derivatives
- Bonds & Fixed Income
- Portfolio Theory & Risk
- Corporate Finance
- Macro & Markets

## Features
- 🎯 Filter by topic & difficulty
- ⏱ Live session timer
- 💡 Full explanations after every answer
- 📊 Topic-wise score breakdown
- 📋 Question-by-question review

## Run Locally

```bash
npm install
npm run dev
```

## Deploy on Vercel
1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → Import project
3. Select your repo → Deploy

That's it. Live in under 2 minutes.
